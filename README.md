# NINA | Links 

Página de links criada para a marca **NINA Velas Artesanais**, com uma identidade visual minimalista, elegante e delicada.

O projeto reúne os principais canais de contato e compra da marca em uma única página, facilitando o acesso dos clientes às redes sociais, ao e-mail e à loja na Shopee.


🔗 **Acesse a página publicada:**  
https://velasnina.github.io/Nina-links/

##  Sobre o projeto

A proposta foi desenvolver uma página de links com uma estética alinhada à identidade visual da NINA Velas Artesanais, utilizando tons neutros, elementos minimalistas e tipografia elegante.

O layout foi pensado para proporcionar uma navegação simples e agradável, tanto em dispositivos móveis quanto em computadores.

## 🚀 Funcionalidades

- Exibição da identidade visual da marca.
- Botões de acesso ao Instagram, e-mail e loja na Shopee.
- Mensagem informativa para o futuro site oficial.
- Botão para compartilhar a página.
- Layout responsivo para celular e computador.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura e conteúdo da página.
- **CSS3:** estilização, cores, tipografia e responsividade.
- **JavaScript:** interações e funcionalidades dos botões.
- **GitHub:** versionamento e armazenamento do código.
- **GitHub Pages:** publicação da página na internet.

## 📱 Responsividade

O layout utiliza regras de CSS para adaptar os tamanhos e o espaçamento dos elementos de acordo com a largura da tela, proporcionando uma experiência adequada em diferentes dispositivos.

## 📂 Estrutura do projeto

- `index.html` — estrutura, estilos e funcionalidades da página.
- `LOGO.jpeg` — imagem da identidade visual da marca.
- `README.md` — documentação do projeto.

## 💡 Aprendizados

Este projeto foi uma oportunidade de praticar a criação de páginas web, a organização de elementos visuais, a adaptação de layouts para diferentes telas e a publicação de um projeto utilizando o GitHub Pages.

Também permitiu explorar como a tecnologia pode ajudar uma marca a organizar sua presença digital.
